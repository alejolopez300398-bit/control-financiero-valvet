# Control financiero Valvet

Aplicacion estatica para registrar movimientos operativos de Valvet y enviarlos a Google Apps Script.

## Despliegue en Vercel

1. Importa este repositorio desde Vercel.
2. Usa la configuracion por defecto para sitio estatico:
   - Framework Preset: `Other`
   - Build Command: vacio
   - Output Directory: `.`
3. Despliega.

La URL del Web App de Google Apps Script se configura en `app.js` mediante `SCRIPT_URL`.
